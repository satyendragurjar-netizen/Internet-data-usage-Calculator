# Internet Data Usage Calculator 📊

A simple Python program to calculate and analyze internet data usage.

## Features

* Enter monthly data limit
* Calculate used and remaining data
* Calculate daily average usage
* Calculate usage percentage
* Estimate monthly data usage
* Calculate extra data and its cost

## Technologies

* Python 3

## How to Run

```bash
python internet_data_calculator.py
```
